# ApexPlanet Internship - Task 2

## Intermediate HTML, CSS and JavaScript

### Requirements completed
1. **Contact Form using HTML and CSS** - name, email, subject and message fields.
2. **JavaScript Form Validation** - required fields, email format and message length validation.
3. **Responsive Layout** - Flexbox navigation, CSS Grid sections and media queries for mobile/tablet/desktop.
4. **Dynamic To-Do List** - add, complete, delete and clear completed tasks using DOM manipulation.

### Files
- `index.html` - webpage structure
- `style.css` - styling, Flexbox, Grid and responsive design
- `script.js` - form validation and dynamic To-Do List
- `README.md` - project information

### Run
Open `index.html` in a browser or use VS Code Live Server.

**Technologies:** HTML5, CSS3, JavaScript ES6, Flexbox, CSS Grid, DOM Manipulation, Media Queries.
